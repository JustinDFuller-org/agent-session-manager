## What it is

Keyboard shortcuts open, close, and move through tabs and panes without leaving the terminal.

## How to use it

The default shortcuts are:

| Shortcut | Action |
| --- | --- |
| ⌘T | New Tab |
| ⌘P | New Pane in Current Tab |
| ⌘W | Close Active Pane |
| ⌘K | Close Active Tab |
| ⌘⇧S | Open Shell Here |
| ⌘R | Refresh Active Pane |
| ⌘1 through ⌘9 | Switch to a tab by position |

To change a configurable shortcut:

1. Open **Settings → Shortcuts**.
2. Select the key field for the action.
3. Enter one key. The command modifier remains fixed.
4. Click outside the field to save the change.

The **⌘1 through ⌘9** tab-switching shortcuts are fixed and cannot be changed.

## What you should see

The changed shortcut is used for that action the next time you invoke it. The tab-switching shortcuts continue to use their fixed positions.

## If it does not work

- If a shortcut does not respond, check its current key in **Settings → Shortcuts**.
- If the key field is blank, click outside it to restore the previous value.
- If ⌘1 through ⌘9 do not switch tabs, create tabs in the positions you want to access.
