Download

Download the notarized Agent Session Manager release for macOS.

What it is

The release DMG is the packaged version of Agent Session Manager for macOS. It is signed with a Developer ID certificate and notarized by Apple.

Before you start

  • Use a Mac running macOS 14 or later.
  • Have at least one supported agent tool installed if you want to create an agent pane immediately.

Download it

Download the latest DMG

Install it

  1. Open the downloaded DMG.
  2. Drag Agent Session Manager to /Applications.
  3. Open Agent Session Manager from Applications.

Release builds can check for newer releases from Settings → About. You can also return to this page to download the latest DMG manually.
